2. Распакуйте этот архив.
3. Откройте репозиторий Alpamys-code/Ai-writing-Balance -> Add file -> Upload files.
4. Загрузите в корень репозитория файлы:
   index.html, style.css, project.css, script.js, config.js, coach.js, ai-tutor-qr.png.
5. Загрузите папку assets целиком с четырьмя изображениями.

8. Откройте https://alpamys-code.github.io/Ai-writing-Balance/ и обновите страницу
   без кэша (Ctrl+F5). Проверьте также на телефоне.

ВАЖНО О ПОМОЩНИКЕ
Новый Scribe AI работает только через настоящую модель Cloudflare Workers AI.
Рабочий сервер уже создан: https://scribe-writing-coach.alpakuday2010.workers.dev/
Его адрес уже добавлен в config.js. Повторно создавать Worker для этого архива
не нужно. Загрузите файлы сайта на GitHub, затем проверьте страницу с телефона.
Покупать API-ключ не нужно: используется бесплатный дневной лимит Cloudflare.
Инструкция в backend/SETUP.txt пригодится для повторного развёртывания.
Дневной лимит не безграничен; после его исчерпания запросы временно прекращаются.
Готовые вопросы сразу отправляются в модель. Для оценки эссе нужны само эссе
и формулировка задания. Разбор включает четыре критерия IELTS Task 2, их оценки,
общую приблизительную оценку, сильные стороны и рекомендации по улучшению.
Это не официальный балл IELTS и не оценка всего Writing: Task 1 не проверяется.
Тренировочного режима и заранее подготовленных оценок больше нет. До подключения
сервис явно сообщает, что ИИ не подключён, и не генерирует фиктивный результат.
Подробная настройка через браузер, без установки программ — backend/SETUP.txt.
Новый ИИ не использует код прежнего сервиса Lovable и не требует доступа к нему.

10 карточек — демонстрационные вымышленные примеры. Они не выдаются за результаты
исследования. В исходном config.js не были настроены email и база отзывов,

и одобрении модератором. Рейтинг больше не служит фильтром публичных отзывов.

ПЕРЕД ЖЮРИ
Проверьте происхождение баллов 20/25, 23/25, 20/25 и наличие исходных работ.
Они сохранены из прежней версии как малый пилот с оцениванием авторами.
Не называйте их доказанным ростом обучения или статистикой большого эксперимента.
Проверяйте реальные ответы модели после подключения. Не демонстрируйте пустое
подключение как работающий ИИ; сайт честно показывает его состояние.
Не говорите, что команда обучила собственную языковую модель: сделан интерфейс,
методика работы и подготовлено подключение готовой модели.

ПРОВЕРКИ
Программные проверки: HTML/локальные ссылки/изображения, переключатели,
FAQ/Feedback, механика 4/10 отзывов, немедленная отправка готового вопроса,
разбор по четырём критериям и обработка недоступного ИИ без подставных ответов.
Сервер проверен на имитациях Cloudflare AI. Дополнительно 22 ноября 2026 года
проверены настоящие ответы развёрнутого сервера: готовый вопрос — HTTP 200;
тестовое эссе с заданием — HTTP 200, четыре критерия, сильные стороны,
рекомендации и вычисленная приблизительная оценка. Это функциональная проверка,
а не доказательство точности оценивания или результат исследовательского пилота.
Визуальная проверка в настоящем браузере и на физическом телефоне не выполнялась.
Для повторения: установите jsdom, выполните node tests/site-checks.cjs и
node tests/backend-checks.mjs. При внешней установке jsdom укажите NODE_PATH.
